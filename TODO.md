# TODO / Known issues

## 1. Thumbnails are hard square-crops that cut the subject out of the photo  — NEEDS ORIGINALS

**Status:** open, deferred until the original images are available.
**Reported by:** Nam, 2026-08-03.

### The problem
Many photo derivatives in `media/img/` were generated by **cropping a 1:1 square out of
the original**, instead of resizing the whole original down. When the original is landscape
or portrait, the square crop throws away most of the frame — often the actual subject.

**Concrete example — `jm34.jpg` ("Tet 3", caption "fireworks for our first Vietnamese New Year"):**
the real photo is **two people with fireworks in the background**. The stored derivative is a
1024×1024 square containing only a small slice of the background sky — the people are gone.
This is the wrong solution: it cropped the full original down to a tiny, meaningless piece.

### Root cause (two separate layers of cropping)
1. **The derivative files themselves.** 88 of 244 photos are stored as ~1:1 squares
   (mostly exactly 1024×1024). For non-square originals this is a destructive center-crop —
   the cut-off edges are **gone from the derivative and cannot be recovered from it**.
   The other 158 photos are fine: full image resized to 1024px long edge, aspect ratio kept.
2. **The CSS crops again on display.** Thumbnails (`.pthumb`, `.athumb`, `.bthumb` in
   `assets/styles.css`) use `object-fit:cover` in square cells, and **even the modal "full"
   view** `.mhero` is locked to `aspect-ratio:4/3; object-fit:cover`. So the whole image is
   never shown, even when the file contains it.

### The fix (the right way — requires the originals)
The originals are **not in this repo** (README: "full-resolution originals are not stored
here") and are **not on the work machine** — they live in Jennie's Google Drive folder.
Once the originals are available:

1. Re-derive every photo: **resize the full original to 1024px on the long edge, preserve
   aspect ratio, NO square crop.** (For the 158 already-correct ones this is a no-op / same result.)
2. Fix the display layer so the full photo shows:
   - Modal hero `.mhero`: drop the fixed `aspect-ratio:4/3` + `object-fit:cover`; use the
     image's natural ratio (or `object-fit:contain`) so the whole photo is visible.
   - Optional: reconsider `object-fit:cover` on the grid thumbnails (a small centered crop
     is acceptable for a *grid*, but only once the underlying file is the full image, so the
     crop is a sensible center-crop rather than a crop-of-a-crop).

**Interim option (no originals needed):** switch the modal `.mhero` to show the full image
for the 158 correctly-sized files. This does NOT fix the 88 squares — those need originals.
